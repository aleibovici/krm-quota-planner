# Governance

[@aleibovici](https://github.com/aleibovici) is the only maintainer of krm-quota-planner, and the person who merges pull requests to `main`.

## Decisions

`main` is the only line of development. The maintainer decides what is merged there. Fixes go to the latest commit on `main`. There are no maintained release branches, no Git tags, and no GitHub Releases. What has landed is recorded in [CHANGELOG.md](CHANGELOG.md).

## Contributing

Anyone can open an issue or a pull request. [CONTRIBUTING.md](CONTRIBUTING.md) is the checklist: run the tests, keep the change focused, and leave out secrets, kubeconfigs, and real cluster files. Contributions are licensed under the [MIT License](LICENSE).

## Security

Security problems are reported in private, through the path in [SECURITY.md](SECURITY.md).

## Conduct

People taking part in this project follow the [Contributor Covenant](CODE_OF_CONDUCT.md). The maintainer enforces it. Reports go to the contact in that file.
